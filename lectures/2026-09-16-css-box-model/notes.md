# Lecture 3 — CSS Box Model (2026-09-16)

Core topic: every element is a box made of content → padding → border → margin.
Covered `width`/`height` (px, %, `max-width`), padding and margin shorthand
syntax, centering with `margin: 0 auto`, border syntax, `border-radius`, and
background color.

Introduced `box-sizing: border-box` and why it's needed (so padding/border don't
inflate the declared width), plus the universal selector `*` and a common
`body { margin: 0; }` reset.

Also covered `display: block` vs `inline` vs `inline-block`, and why width
doesn't apply to inline elements like `<a>` by default.

**Practice:** a plain box, a profile card, a product card, styled button variants, a "Restaurant Card" challenge, and DevTools box-model inspection.
