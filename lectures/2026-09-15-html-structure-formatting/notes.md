# Lecture 2 — HTML Structure & Code Formatting (2026-09-15)

Deep dive on `head` vs `body` — head holds page metadata (not visible), body
holds everything the user sees. Practiced spotting structural mistakes (visible
content misplaced in `head`, missing tags).

Covered clean-code habits: indentation, consistent spacing, VS Code's auto-format
shortcut, correct nesting of tags, self-closing elements (`img`, `br`, `hr`,
`meta`, `link`), and HTML comments.

Also revisited CSS formatting conventions and naming — using descriptive
`kebab-case` class names instead of vague ones.

**Practice:** fixed broken HTML, built a movie page (HTML only, then styled with CSS), a profile card, and an About Me page.

**Homework:** "My City" page — name, photo, history, notable places, links, footer.
