# Lecture 1 — How the Web Works (2026-09-14)

Covered the basics of how the internet delivers a webpage: browser (client) sends
a request, DNS resolves the domain to a server IP, server responds, browser
renders the HTML/CSS/JS. Also covered HTTP vs HTTPS, status codes (200/404/500),
hosting, and the frontend/backend split.

Then moved into first HTML: the boilerplate (`<!DOCTYPE>`, `html`, `head`, `body`),
common tags (headings, paragraphs, links, images, lists, `div`), attributes, and
a first intro to semantic tags (`header`, `nav`, `main`, `section`, `footer`).

Finished with first CSS: linking a stylesheet, basic selector syntax, `class` vs
`id`, and simple properties (color, font, background, padding/margin basics).

**Practice:** built a small personal profile page combining HTML structure + CSS styling.

**Homework:** About Me / Portfolio page — header, about, skills, favorite links, contact, footer.
